Columns added (appended after the original columns):

  fix_branch_primary
      The main (master-based) branch carrying the fix, e.g. "f003-r2".
      "(none)" for findings with no fix branch.

  fix_branch_all
      All branches carrying the fix (primary + per-version backports),
      semicolon-separated. Rollup branches are annotated "(rollup)".

  fix_merged_upstream
      Whether the finding's specific fix commit (by git patch-id) has
      landed in upstream apache/spark, matched against upstream/master
      and upstream/branch-4.x. Survives Spark's squash-merge
      (dev/merge_spark_pr.py) where the merged SHA differs from the
      branch tip.
      Values:
        merged:master+branch-4.x  fix commit in both master and branch-4.x
        merged:branch-4.x         fix commit in branch-4.x only
        not-merged               fix commit not in master nor branch-4.x
        no-fix-branch            no dedicated fix branch found
